# phoneMic · Android 端 v1.0.2

把手机变成电脑麦克风（和耳机）。配套电脑端见 `phoneMic-Windows`。

## 功能

| 项 | 说明 |
|---|---|
| **长按说话** | 按住大圆按钮才开麦克风，松手立刻停（状态栏录音图标会消失） |
| **点按常开** | 点一下持续录音，再点一下停 |
| **播放电脑的声音** | 勾上后电脑放视频/音乐，手机里能听到（手机当耳机） |
| 自动发现电脑 | 打开就找，不用输 IP |
| 后台保活 | 切后台、息屏继续工作 |

顶部横幅颜色就是状态：**红=正在录音**，绿=已连接待命，琥珀=搜索中，灰=未连接。

## 用法

1. 安装后授予「麦克风」权限
2. 电脑上先打开 phoneMic 并点「开始」
3. 手机 App 自动显示电脑地址，变绿即可说话

## 和电脑端模式的关系

电脑端有三个模式（只当麦克风 / 麦克风+监听 / 手机当耳机）。手机这边只有两个开关：

- **模式 / 说话按钮** —— 控制「手机 → 电脑」的方向
- **播放电脑的声音** —— 控制「电脑 → 手机」的方向

想当耳机用时：电脑端选模式③，手机端把这个勾打开。

## 常见问题

| 现象 | 处理 |
|---|---|
| 一直搜不到电脑 | 电脑程序开了吗、点开始了吗；是否同一 WiFi；点「重新搜索」 |
| 找到了但连上就断 | 检查电脑防火墙是否拦了 UDP 47810 |
| 息屏一会儿就断 | 到系统设置里把本 App 加入电池优化白名单 |
| 说话对方没反应 | 电脑端设置里点「设为默认麦克风」 |

## 技术

纯 Java，**零第三方依赖**（不使用 AndroidX / Compose / Kotlin），APK 约 30KB。
APK 用固定密钥签名（`phonemic.jks`，密钥存在 CI 的仓库 Secret 里，不在代码库中），
所以新版可以**直接覆盖安装**，不用先卸载旧的。
最低 Android 8.0（API 26），Android 17 直接可用。
通信：UDP 47810，裸 PCM 48kHz/16bit/单声道，10ms 一帧（960B）。

| 包类型 | 方向 | 内容 |
|---|---|---|
| `0x01` 上行音频 | 手机→电脑 | `[01][seq:u16][PCM 960B]` |
| `0x02` 下行音频 | 电脑→手机 | `[02][seq:u16][PCM 960B]` |
| `0x10/0x11` 说话开始/结束 | 手机→电脑 | `[10]` / `[11]` |
| `0x12` 心跳 | 手机→电脑 | `[12][mode]` |
| `0x22` 应答 | 电脑→手机 | `[22]` |
| `0x20/0x21` 发现/应答 | 双向 | 手机广播，电脑回复名字 |
