# phoneMic · Android 端

把手机变成电脑麦克风。配套的电脑程序见另一个仓库 `phoneMic-Windows`。

---

## 功能

| 模式 | 行为 |
|---|---|
| **长按说话** | 按住大圆按钮期间才开麦克风；松手立刻停（状态栏录音图标消失，是真的关了） |
| **点按常开** | 点一下开始持续录音，再点一下停止 |

- 打开 App 自动在局域网里搜索电脑，**不用输 IP**
- 切后台、息屏都继续工作（前台服务 + 唤醒锁）
- 顶部横幅颜色就是状态：**红=正在录音**，绿=已连接待命，琥珀=搜索中，灰=未连接

> 联动按键（比如说话时自动按住 Alt）在电脑端设置，手机上不用配。

---

## 安装

1. 安装 `phoneMic-apk`（允许「未知来源」）
2. 打开后授予「麦克风」权限
3. 电脑上先打开 phoneMic 主程序并点「开始」
4. 手机 App 会自动显示电脑地址，状态变绿即可说话

---

## 常见问题

| 现象 | 处理 |
|---|---|
| 一直「正在搜索电脑」 | ① 电脑程序开了吗、点开始了吗 ② 是否同一 WiFi ③ 点「重新搜索」 |
| 找到了但连上就断 | 检查电脑防火墙是否拦了 UDP 47810（本程序首次监听时 Windows 会弹提示，选允许） |
| 息屏一会儿就断 | 到系统设置把本 App 加入**电池优化白名单**（各品牌位置不同，搜「电池优化」） |
| 说话对方没反应 | 电脑端输出设备要选 `CABLE Input`，语音软件的麦克风要选 `CABLE Output` |

## 技术说明

| 项 | 说明 |
|---|---|
| 语言 | 纯 Java，**不使用 AndroidX / Compose / Kotlin** |
| 依赖 | 零第三方依赖 |
| 体积 | APK 约 60–90KB |
| 最低版本 | Android 8.0（API 26），Android 17 直接可用 |
| 通信 | UDP 47810，裸 PCM 48kHz/16bit/单声道，10ms 一帧（960 字节） |

### 协议

| 类型 | 方向 | 内容 |
|---|---|---|
| `0x01` 音频 | 手机→电脑 | `[01][seq:u16][PCM 960B]` |
| `0x10` 说话开始 | 手机→电脑 | `[10]` |
| `0x11` 说话结束 | 手机→电脑 | `[11]` |
| `0x12` 心跳 | 手机→电脑 | `[12][mode]` 每秒一次 |
| `0x20` 发现请求 | 手机→广播 | `[20]` |
| `0x21` 发现应答 | 电脑→手机 | `[21][nameLen][name utf8]` |

电脑端 2 秒收不到任何包即判定断线，并强制松开所有联动按键。
